# Obelune Data Viewer

C# のオブジェクト（`List<T>` / `T[]` のテーブル）で作ったリレーショナルなデータベースを、Unity エディタで参照・検索・検査する。

**開発中（検証 1）。** 仕様と設計はリポジトリの `docs/data-viewer/` にある。

## 導入

Package Manager の「Add package from git URL」に次を入れる。

```
https://github.com/kairamu061-dev/UnityEditorExtension.git?path=UnityProject/Packages/com.obelune.data-viewer
```
