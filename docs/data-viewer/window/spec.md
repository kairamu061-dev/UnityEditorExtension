# window 仕様

操作の流れと各画面の表示は [`../spec.md`](../spec.md#画面操作フロー) にある。ここには、window だけが持つ決まりを書く。

## 機能一覧

| # | 機能名 | 説明 | テストケース |
|---|--------|------|------------|
| 1 | テーブルの一覧 | テーブルの名前（同じ名前があればパス）と行数・問題の数を出す | E-01 |
| 2 | 行の一覧 | 選んだテーブルの全列。主キーの列に印。`ref` の列には参照先の最初の `string` 列を添える。参照切れのセルは目立たせる | E-02, I-01 |
| 3 | 並べ替え | 列の見出しで昇順・降順。並べ替えの順は列ごとに一度だけ計算し、ウィンドウの側に覚えておく（Database には書かない） | E-02 |
| 4 | 行の詳細 | 全列の値・参照先・参照元（テーブルごとの件数と行） | E-03 |
| 5 | 移動と履歴 | 参照先・参照元・問題をクリックすると、そのテーブルのその行を選んで見える位置まで送る。戻る・進む | E-03, E-04 |
| 6 | 検索欄 | 打鍵ごとに検索する（前の検索はやめる）。範囲は「全テーブル」か「このテーブル」。全テーブルのときは、テーブルの一覧に当たった件数を出す | E-02 |
| 7 | 問題の一覧 | 種類・場所・内容。クリックで該当の行へ、設定の問題なら設定の画面へ移る | E-04 |
| 8 | 状態の表示 | 読み込み中の進み具合、最後の読み込みの計測（冊数・時間） | E-05 |
| 9 | 選んでいる場所を覚える | 選んでいるテーブルと行・検索語を、ドメインリロードのあとも保つ | I-01 |
| 10 | スキン | ライトスキン・ダークスキンの両方で読める | E-06 |
| 11 | 設定の画面 | settings のペイン。ソースの選択を含む | settings E-01 |

## エラーケース

| 条件 | メッセージ / 挙動 |
|------|------------------|
| ソースが未設定 | 中央に案内と設定の画面へのボタン |
| 選んでいたテーブルが、読み直しで消えた（パスが見つからない） | テーブルの選択を外し、その旨を状態の表示に出す |

## 未対応ケース

- 複数のウィンドウを開いて、それぞれ別のテーブルを見ること（1 つだけ開ける）
