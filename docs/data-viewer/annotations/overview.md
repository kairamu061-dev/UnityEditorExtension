# annotations 概要

親: [data-viewer](../overview.md)

## 目的・背景

データベースの値は `int` で持つが、その値を表す名前が別にある、という場面がある（`character_id = 1` のキャラクター名は「Claude」）。名前そのものはデータベースに入れないが、ビューアでは値と一緒に見たい。

この項目は、データベースの外にある「値 → 名前」の対応（補助情報）を読み込み、テーブルの列に結び付けて表示できるようにする。

## スコープ

### 作るもの

- 補助情報の集まり（値 → 名前・説明）の型と、受け取り方（組み込みの CSV と、利用者が書くもの）
- 補助情報を、テーブルの主キーか、特定の列に結び付ける設定
- 行の一覧・行の詳細での表示（表示の仕方は検証で決める）

### 作らないもの

- 補助情報の編集
- 補助情報をデータベースに書き戻すこと

## 制約

- 表示の仕方は未定（利用者の判断待ち）。検証で並べて見比べてから決める（`../tasks.md` の検証 1）

## 完了条件

- 表示の仕方が決まり、`spec.md` に書かれている
- `test-cases.md` のテストが通る

## 画面イメージ

検証で決める。候補は `spec.md` の「表示の仕方（未定）」にある。
