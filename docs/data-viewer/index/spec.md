# index 仕様

## 機能一覧

| # | 機能名 | 説明 | テストケース |
|---|--------|------|------------|
| 1 | 主キーで引く | テーブルと主キーの値から、行の番号を返す | U-01 |
| 2 | 主キーの重複 | 同じ値が 2 行以上あれば、2 行目以降を問題にする。引くときは最初の行を返す | U-02 |
| 3 | 空の主キー | 主キーが値なし（`string` の null）の行を問題にする | U-03 |
| 4 | 参照の解決 | 参照の列の各行について、参照先の行の番号を求める。整数は数値で、`string` は文字列で、`enum` は数値で比べる | U-04, U-05 |
| 5 | 参照切れ | 参照先に見つからない値を問題にする。値なしと「参照なしとみなす値」は問題にしない | U-06, U-09 |
| 6 | 解決できない参照 | settings が問題にした参照（型が合わない・参照先がない）は、全行を「解決できない」にする | U-07 |
| 7 | 参照元 | ある行を参照している（テーブル, 列, 行）の一覧を返す | U-08 |
| 8 | 検索 | 全部の列の表示の文字列の部分一致。大文字小文字を区別しない。範囲は全テーブルか 1 テーブル | U-10, U-11, U-13 |
| 9 | 絞り込みの検索 | 直前の検索語を含む語で検索したとき、直前の結果の中だけを探す。結果は最初から探した場合と一致する | U-12 |

## 未対応ケース

- 正規表現・列を指定した検索
