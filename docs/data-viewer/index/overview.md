# index 概要

親: [data-viewer](../overview.md)

## 目的・背景

Snapshot と設定から、読み取り専用のデータベース（`Database`）を作る。主キーで行を引く・参照を解決する・参照元を逆に引く・検索する、を目標の速さで行い、データの不備を問題として集める。

## スコープ

### 作るもの

- 主キーの索引、主キーの重複・空の検出
- 参照の解決と参照切れの検出（参照なしとみなす値を含む）
- 参照元の逆引き
- 検索（部分一致、大文字小文字を区別しない）と絞り込み

### 作らないもの

- 並べ替え（window が、表示する列について行う）
- 一部だけの作り直し。読み直しのたびに全部を作る（**推測**: 10 万行で数十 ms。fixtures I-06 で測る）

## 制約

- `Obelune.DataViewer.Core` に入る。スレッドプールで動く。作った Database は変更しない（`../design.md` のスレッド）
- 性能の目標（`../spec.md`）: 検索は 1 打鍵 50 ms、ジャンプは 16 ms

## 完了条件

- `test-cases.md` の U-01〜U-13 が通る
- fixtures I-03・I-05・I-06 で目標を満たす
