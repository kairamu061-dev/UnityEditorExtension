# settings 仕様

## 機能一覧

| # | 機能名 | 説明 | テストケース |
|---|--------|------|------------|
| 1 | 主キーの設定 | テーブルのパスと列の名前。整数・`string`・`enum` の列だけを選べる | U-01 |
| 2 | 参照の設定 | 参照元のテーブルのパスと列の名前、参照先のテーブルのパス、参照なしとみなす値（任意） | U-02 |
| 3 | テーブル・列がない | 設定にあるテーブルのパス・列の名前がデータにないとき、問題にし、その設定を無視する | U-03 |
| 4 | 型の種類が合わない | 参照の列と参照先の主キーの型の種類（整数・文字列）が違うとき、問題にし、その参照を解決しない | U-04 |
| 5 | 参照先に主キーがない | 参照先のテーブルに主キーが設定されていないとき、問題にする | U-05 |
| 6 | 保存と読み込み | `ProjectSettings/Obelune.DataViewer.json`。キーの順を固定し、差分が読みやすいようにする | U-01, U-02 |
| 7 | 設定の画面 | 候補（テーブル・列）を取り出しの結果から並べ、選ぶ。変えたらすぐ保存し、索引を作り直す | E-01 |
