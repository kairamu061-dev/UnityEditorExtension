# fixtures 概要

親: [data-viewer](../overview.md)

## 目的・背景

性能の目標（`../spec.md`）を、実際の規模のデータで測るための合成データの生成と計測。実際のデータが揃う前から、目標を満たすかを確かめられるようにする。

## スコープ

### 作るもの

- 例の DataContainer の形（キャラクター・中間のテーブル・アビリティなど）の型と、それを指定した規模で埋めた ScriptableObject のアセット
- 性能の目標ごとの計測（EditMode テスト）

### 作らないもの

- 利用者の実際の型に合わせたデータ（実際の型が分かったら、型を寄せる）

## 制約

- 型と生成器はテストのアセンブリの中に置き、配布物の本体には入れない
- 生成したアセットは開発用プロジェクトの一時的な場所に置き、コミットしない（10 万行のテキストのアセットは大きい）
- 同じ設定からは、いつも同じ中身を作る（乱数の種を固定する）
- 計測の値は、ホストのマシンで MCP 経由で走らせたものを `../dev-notes.md` に残す

## 完了条件

- `test-cases.md` の I-01〜I-06 が通り、値が `../dev-notes.md` にある
