# source 仕様

## 機能一覧

| # | 機能名 | 説明 | テストケース |
|---|--------|------|------------|
| 1 | ソースの一覧 | 組み込みのアセットのソースと、`IDataViewerSource` を実装した型（`TypeCache` で見つける）を並べる | U-01 |
| 2 | アセットのソース | 設定にあるアセットのパスで `AssetDatabase.LoadMainAssetAtPath` し、それをルートにする | I-01 |
| 3 | 変更の検出（アセット） | そのアセットが再インポートされたら読み直す（`AssetPostprocessor.OnPostprocessAllAssets`） | I-02 |
| 4 | 変更の検出（利用者のソース） | ソースの `Changed` を受けたら読み直す | I-02 |
| 5 | 手での読み直し | 「再読込」 | I-02 |
| 6 | 計測 | アセットの読み込み・取り出し・索引の作成・差し替えの時間と、テーブル・行の数を `DataViewerDiagnostics.Last` に残す | I-03 |

## エラーケース

| 条件 | メッセージ / 挙動 |
|------|------------------|
| アセットがない | 案内を出す |
| 利用者のソースが例外を出す・null を返す | 例外の内容を状態の表示に出し、前回の Database を出し続ける |
| 利用者のソースの型が見つからない（名前を変えた・消した） | 問題として報告し、ソースの選択を促す |
