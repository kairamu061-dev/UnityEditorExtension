# source 概要

親: [data-viewer](../overview.md)

## 目的・背景

データの入れ物（ルート）の形は利用者がまだ決めていない。ビューアは「ルートのオブジェクトを 1 つ受け取る」ことだけを決め、受け取り方を差し替えられるようにする。あわせて、データが変わったことを知り、読み直しを始める。

## スコープ

### 作るもの

- ソースの型（利用者が実装する Editor 側のインターフェース）
- 組み込みのアセットのソース（`UnityEngine.Object` のアセットを 1 つ指定する）
- 読み直しの流れ: ルートを受け取る → 取り出し → 索引 → 差し替え。段階ごとの計測

### 作らないもの

- 独自のファイル形式の読み込み（利用者がソースの中で書く）

## 制約

- `Obelune.DataViewer.Editor` に入る。ソースはメインスレッドで呼ぶ

## 完了条件

- `test-cases.md` の U-01、I-01〜I-03 が通る
