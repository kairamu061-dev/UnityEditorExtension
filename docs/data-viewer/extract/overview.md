# extract 概要

親: [data-viewer](../overview.md)

## 目的・背景

ルートのオブジェクトからテーブルを見つけ、列ごとの配列（Snapshot）に取り出す。取り出したあとは、ユーザーのオブジェクトに触れずに索引・検索・表示ができる。

## スコープ

### 作るもの

- テーブルの発見（`../spec.md` の「データの決まり」）
- 列の決定と、式木でコンパイルした取り出し
- 文字列表への集約と、表示・検索の派生データ（数値の表示の文字列・小文字の写し）
- テーブルの名前と識別（パス）

### 作らないもの

- 主キー・参照の判断（settings と index）

## 制約

- 取り出しの仕組みは `Obelune.DataViewer.Core`。どのフィールドをたどるかの判定（`[SerializeField]` など）は `Obelune.DataViewer.Editor`（`../design.md` のアセンブリ）
- メインスレッドで動く。10 万行で数十 ms を目標にする

## 完了条件

- `test-cases.md` の U-01〜U-10 が通る
- fixtures I-02 で取り出しの時間を測っている
