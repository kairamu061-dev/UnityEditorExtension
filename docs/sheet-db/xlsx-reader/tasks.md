# xlsx-reader タスク

## 実装タスク一覧

- [ ] `.gitattributes` に `*.xlsx binary`、`.gitignore` に `~$*` を足す（実物の Excel で保存したテスト用のブックをコミットする前に）
- [ ] テスト用の小さな xlsx の組み立て（テストの中で zip を作る補助）
- [ ] シートの一覧と共有文字列
- [ ] セルの読み込み（値の種類・位置・数式）
- [ ] 壊れたブックの例外
- [ ] 実物の Excel で保存したテスト用のブック（数式・書式付きの文字列・IME で入力した日本語・空のセル・`AA` 以降の列を含む）

## テストの線引き

| 対象 | 自動で書けるか | 置き場所 |
|---|---|---|
| セルの値・位置・数式・共有文字列 | **書ける**（テストの中で xlsx を組み立てる） | `Obelune.SheetDb.Core.Tests`（MCP 経由。`docs/testing.md`） |
| 実物の Excel が作る xlsx の形 | **書ける**（保存したブックをコミットしておけば） | 同上 |
| Excel が開いているブックを読めるか | 実機が要る | `test-cases.md` の E-01（手で Excel を開いておく） |
