# xlsx-reader 仕様

## 機能一覧

| # | 機能名 | 説明 | テストケース |
|---|--------|------|------------|
| 1 | シートの一覧 | `xl/workbook.xml` のシートの順で、名前と zip の中の場所を返す。場所は `xl/_rels/workbook.xml.rels` で引く（相対・絶対のどちらの書き方も） | U-01 |
| 2 | 共有文字列 | `xl/sharedStrings.xml` を読む。書式付きの文字列（`<r><t>` が複数）はつないで 1 つにする。共有文字列のないブックも読める | U-02, U-11 |
| 3 | セルの値の種類 | 数値・共有文字列・インライン文字列（`t="inlineStr"`）・数式の文字列の結果（`t="str"`）・真偽値（`t="b"`）・エラー値（`t="e"`）・値なし | U-03〜U-07 |
| 4 | 数式 | `<f>` があっても、`<v>` の計算結果を返す。`<v>` がなければ「値なし」で、数式があったことを印として付ける | U-07 |
| 5 | 位置 | 各セルの行番号と列番号（0 始まり）を返す。列は `A`〜`XFD`。`r` 属性が省かれた行・セルは、直前の次の位置とする | U-08, U-09 |
| 6 | 空のセル・空の行 | 省かれたセルは返さない（呼び出し側が空として扱う） | U-08, U-10 |
| 7 | 壊れたブック | zip として開けない・必要な部分がないとき、何が足りないかを含む例外を出す | U-12 |
| 8 | 開いているブック | 他のプロセスが開いていても読めるように、読み取り共有と書き込み共有を許して開く | E-01 |

## 画面・操作フロー

なし（ライブラリ）。

## エラーケース

| 条件 | メッセージ / 挙動 |
|------|------------------|
| zip ではない | `XlsxFormatException`（「zip として開けない」） |
| `xl/workbook.xml` がない | `XlsxFormatException`（足りない部分の名前を含める） |
| 共有文字列の番号が範囲外 | そのセルをエラー値として返す（ブック全体は止めない） |

## 未対応ケース

- 暗号化されたブック・`.xlsb`・`.xlsm` のマクロ
- 1904 年始まりの日付の設定（日付を数値のまま返すので、扱わない）
