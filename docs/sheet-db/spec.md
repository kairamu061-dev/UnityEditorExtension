# sheet-db 仕様

## 機能一覧

テストケースの ID は、担当するサブ項目の `test-cases.md` にある（`xlsx-reader U-01` = `docs/sheet-db/xlsx-reader/test-cases.md` の U-01）。

| # | 機能名 | 説明 | テストケース |
|---|--------|------|------------|
| 1 | データフォルダの設定 | データベースとして読むフォルダを、プロジェクトからの相対パスで指定する。サブフォルダも読む | loader U-01, loader I-01 |
| 2 | ブックの発見 | フォルダの下の `*.xlsx` を集める。`~$` で始まる一時ファイルは除く | loader U-02, loader U-03 |
| 3 | xlsx の読み込み | セルの値を読む。共有文字列・インライン文字列・数値・真偽値・エラー値・数式の計算結果・空のセルの省略・列番号（`AA` など）。日付は数値（シリアル値）のまま読む | xlsx-reader U-01〜U-12 |
| 4 | スキーマの解釈 | シート＝テーブル。1 行目＝列名、2 行目＝型。`_` で始まるシートと `#` で始まる列は読まない。テーブル名は全ブックで一意 | schema U-01〜U-06, index U-14 |
| 5 | 型の変換と型の不一致の検出 | セルの値を列の型に変換する。変換できないセルを問題として報告する | schema U-07〜U-11 |
| 6 | 主キー | 各テーブルの 1 列目を主キーにする。重複・空の主キーを問題として報告する | index U-01〜U-03 |

| 8 | 参照元の一覧 | ある行を参照している行を、全テーブルから集める | index U-08, index U-09 |

| 14 | キャッシュ | 読み込んだ結果を `Library/` に保存し、次にウィンドウを開くときは変わったブックだけを読み直す | cache U-01〜U-05, cache I-01 |

## データの書き方（Excel 側）

```
シート名 = テーブル名（全ブックで一意）
  1 行目: 列名        id     | name    | category_id     | price | #メモ
  2 行目: 型          int    | string  | ref:Categories  | float |
  3 行目〜: データ     1024   | Iron... | 3               | 120   | ここは読まない
```

- **1 列目が主キー**になる。型は `int` か `string`
- **型**: `int` / `float` / `string` / `bool` / `ref:<テーブル名>`
  - `ref:<テーブル名>` の値は、参照先テーブルの主キーの値を書く。参照先の主キーが `int` ならこの列も整数として読む
  - 空のセルは「値なし」。`ref` の列が空なら「参照なし」で、参照切れには数えない
- `_` で始まるシートは読まない（作業用・集計用のシートに使う）
- 列名が `#` で始まる列は読まない（メモ・数式の作業列に使う）
- 型の行が空の列は `string` として読む
- 数式のセルは、Excel が保存した計算結果を読む

## 性能の目標

規模: 全体で 10 万行・50 ブック・1 テーブル最大 2 万行（列は 1 テーブル 10〜30 列）。

| 操作 | 目標 | 測り方 |
|---|---|---|
| ウィンドウを開いてから、テーブルの一覧と最初のテーブルが出るまで（キャッシュがあるとき） | 0.5 秒以内 | fixtures I-03 |
| 検索の 1 打鍵ごとに、結果の表示が更新されるまで | 50 ms 以内 | fixtures I-03 |
| 参照先へのジャンプ（クリックから表示まで） | 16 ms 以内（1 フレーム） | fixtures I-05 |
| 2 万行のブックを 1 冊保存してから、エディタに戻って表示が更新されるまで | 1 秒以内 | fixtures I-06 |
| キャッシュがないときの全体の読み込み | 目標の時間は置かない。**エディタを止めない**（読み込み中も操作でき、進み具合が出る） | fixtures I-02 |

## 画面・操作フロー

1. `Tools/Obelune/Sheet DB` でウィンドウを開く
2. 初回は、データフォルダが未設定であることが表示される。フォルダを選ぶ
3. 読み込みが始まり、進み具合が出る。読み終わったテーブルから一覧に出る
4. 左のテーブルを選ぶと、中央に行の一覧が出る
5. 行を選ぶと、右に詳細が出る。参照の値をクリックすると、参照先のテーブルのその行に移る。「戻る」で元の行に戻る
6. 上の検索欄に文字を入れると、行の一覧がその文字を含む行に絞られる
7. 「検査」の問題の数をクリックすると、問題の一覧が出る。問題を選ぶとその行に移る
8. Excel でブックを編集して保存し、エディタに戻ると、そのブックだけが読み直される

## 各画面 / 状態の詳細

### テーブル一覧（左）

- **表示内容**: ブック（ファイル名）ごとにテーブルを並べ、行数を出す。問題があるテーブルには数を出す。最下部に問題の合計
- **操作**: テーブルを選ぶ。ブックの右クリックで「Excel で開く」「このブックを読み直す」
- **遷移先**: 中央の行の一覧

### 行の一覧（中央）

- **表示内容**: 列名と型を見出しに出す。`ref` の列は値の横に参照先の主キー以外の列（最初の `string` 列）を添える。参照切れのセルは目立たせる
- **操作**: 行を選ぶ。列の見出しで並べ替え
- **遷移先**: 右の行の詳細

### 行の詳細（右）

- **表示内容**: 全列の値。参照先（クリックできる）。参照元のテーブルごとの件数と、その行の一覧
- **操作**: 参照先・参照元をクリックしてその行に移る。「戻る」「進む」
- **遷移先**: 移った先のテーブルの行

### 読み込み中

- **表示内容**: 読み終わった冊数と全体の冊数、経過時間
- **操作**: 読み終わったテーブルはすぐ使える。読み込み中も検索できる（読み終わった範囲で）

## エラーケース

| 条件 | メッセージ / 挙動 |
|------|------------------|
| データフォルダが未設定・存在しない | ウィンドウに「データフォルダを選んでください」とフォルダ選択のボタンを出す |
| xlsx が壊れている・xlsx ではない | そのブックを問題として報告し、ほかのブックは読み続ける |
| ブックが別のプロセスに書き込み中で読めない | 少し待って読み直す。読めなければ、そのブックを問題として報告し、前回の内容を出し続ける |
| 同じテーブル名が複数のシートにある | 問題として報告する。後から見つかった方を読まない |
| `ref:` の参照先テーブルが存在しない | その列を問題として報告し、`string` として出す |
| 主キーの列の型が `int` / `string` 以外 | 問題として報告し、`string` として読む |
| 数式の計算結果が保存されていない | そのセルは「値なし」。問題として報告する（件数をまとめて） |

## 未対応ケース

- 1 つのセルに複数の参照を書く（`3,5,8` など）。多対多は中間のテーブルで表す
- 複数の列を組み合わせた主キー
- 列の型としての `enum`・日付・ベクトルなど。必要になったら型を足す
- 結合したセルの扱い（左上のセルだけが値を持つ。ほかは空として読む）
- Excel の「テーブル」機能（ListObject）の範囲。シート全体を読む
- 特定のセルを選んだ状態で Excel を開くこと（OS の関連付けで開くと、セルを指定できない。**推測**）
