# schema 概要

親: [sheet-db](../overview.md)

## 目的・背景

xlsx-reader が返すセルの並びを、見出しの行（列名・型）に従って、型の付いたテーブル（`TableData`）にする。型に合わないセルを問題として集める。

## スコープ

### 作るもの

- 見出しの解釈（1 行目＝列名、2 行目＝型）と、読まないシート・列の判定
- セルの値から列の型への変換
- 問題（`Problem`）の記録。どのブック・テーブル・Excel の何行目・どの列か

### 作らないもの

- テーブルをまたぐ検査（主キーの重複・参照切れ・テーブル名の重複）。index で行う

## 制約

- `Obelune.SheetDb.Core` に入る。1 冊のブックだけを見て完結する（ブック同士を並列に処理するため）
- 列ごとの配列で持つ（`../design.md` のメモリの持ち方）
