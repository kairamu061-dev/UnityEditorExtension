# fixtures 概要

親: [sheet-db](../overview.md)

## 目的・背景

性能の目標（`../spec.md`）を、実際の規模のデータで測るための合成データの生成と計測。実物のデータが揃う前から、目標を満たすかを確かめられるようにする。

## スコープ

### 作るもの

- 指定した規模の xlsx を作る生成器（テストのアセンブリの中。配布物の本体には入れない）
- 性能の目標ごとの計測（EditMode テスト）

### 作らないもの

- 書式・数式を含む本物らしいブック（形の確かめは xlsx-reader の実物のブックで行う）

## 制約

- 生成したファイルは `Library/Obelune/SheetDbFixtures/` に置き、コミットしない
- 同じ設定からは、いつも同じ中身を作る（乱数の種を固定する）
- 計測の値は、ホストのマシンで MCP 経由で走らせたものを `../dev-notes.md` に残す

## 完了条件

- `test-cases.md` の I-01〜I-06 が通り、値が `../dev-notes.md` にある

## 画面イメージ

画面はない。
