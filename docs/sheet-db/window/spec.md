# window 仕様

操作の流れと各画面の表示は [`../spec.md`](../spec.md#画面操作フロー) にある。ここには、window だけが持つ決まりを書く。

## 機能一覧

| # | 機能名 | 説明 | テストケース |
|---|--------|------|------------|
| 1 | テーブルの一覧 | ブックごとにまとめ、行数と問題の数を出す | E-01 |
| 2 | 行の一覧 | 選んだテーブルの全列。`ref` の列には参照先の最初の `string` 列を添える。参照切れのセルは目立たせる | E-02, I-01 |
| 3 | 並べ替え | 列の見出しで昇順・降順。並べ替えの順は列ごとに一度だけ計算し、覚えておく | E-02 |
| 4 | 行の詳細 | 全列の値・参照先・参照元（テーブルごとの件数と行） | E-03 |
| 5 | 移動と履歴 | 参照先・参照元・問題をクリックすると、そのテーブルのその行を選んで見える位置まで送る。戻る・進む | E-03, E-04 |
| 6 | 検索欄 | 打鍵ごとに検索する（前の検索はやめる）。範囲は「全テーブル」か「このテーブル」。全テーブルのときは、テーブルの一覧に当たった件数を出す | E-02 |
| 7 | 問題の一覧 | 種類・場所・内容。クリックで移動 | E-04 |
| 8 | 状態の表示 | 読み込み中の進み具合、最後の読み込みの計測（冊数・時間） | E-05 |
| 9 | Excel で開く | `EditorUtility.OpenWithDefaultApp` でブックを開く | E-06 |
| 10 | 選んでいる場所を覚える | 選んでいるテーブルと行・検索語を、ドメインリロードのあとも保つ | I-01 |
| 11 | スキン | ライトスキン・ダークスキンの両方で読める | E-07 |

## エラーケース

| 条件 | メッセージ / 挙動 |
|------|------------------|
| データフォルダが未設定 | 中央に案内とフォルダ選択のボタン |
| 選んでいたテーブルが、読み直しで消えた | テーブルの選択を外し、その旨を状態の表示に出す |

## 未対応ケース

- 複数のウィンドウを開いて、それぞれ別のテーブルを見ること（1 つだけ開ける）
