# loader 仕様

## 機能一覧

| # | 機能名 | 説明 | テストケース |
|---|--------|------|------------|
| 1 | データフォルダの設定 | プロジェクトからの相対パスを `ProjectSettings/Obelune.SheetDb.json` に保存する。チームで共有するため Git で管理する | U-01, I-01 |
| 2 | ブックの発見 | データフォルダの下（サブフォルダを含む）の `*.xlsx`。`~$` で始まるもの・隠しファイルを除く | U-02 |
| 3 | 変わったブックの判定 | 前回の一覧と今の一覧（パス・大きさ・更新時刻）から、足された・変わった・消えたブックを求める | U-03 |
| 4 | 裏での読み込み | ブックごとに、キャッシュがあれば読み戻し、なければ xlsx を読んでキャッシュに書く。並列の数は CPU の数 − 1 | I-02 |
| 5 | 読めないブック | 読み込み中の共有違反は、200 ms おきに 3 回まで読み直す。読めなければ問題にし、前回の内容を使い続ける | I-02 |
| 6 | 差し替え | 読み終わったブックから順に、Database を差し替える。差し替えはメインスレッドで、1 回の代入で行う | I-02 |
| 7 | 変更の検出 | エディタが前面に戻ったとき、ウィンドウが前面に来たとき、「再読込」を押したとき、判定（3）を行う | I-02 |
| 8 | 計測 | 段階ごとの所要時間と、キャッシュから読んだ冊数・読み直した冊数・失敗した冊数を `SheetDbDiagnostics.Last` に残す | I-03 |

## エラーケース

| 条件 | メッセージ / 挙動 |
|------|------------------|
| データフォルダが `Assets/` の中 | 警告を出す（Unity が xlsx と `~$` の一時ファイルを取り込み、`.meta` を作るため。**推測**: 実際に作られるかは未確認）。読み込みは行う |
