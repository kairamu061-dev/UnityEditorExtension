# loader 概要

親: [sheet-db](../overview.md)

## 目的・背景

データフォルダのブックを見つけ、キャッシュか xlsx から読み、Database を作ってウィンドウに渡す。エディタを止めずに、裏で並列に行う。ブックが保存されたら、そのブックだけを読み直す。

## スコープ

### 作るもの

- データフォルダの設定（プロジェクトで共有する）
- ブックの発見
- 裏での読み込み（ブックごとに並列）と、Database の差し替え
- 変更の検出（エディタに戻ったとき・手で読み直したとき）
- 読み込みの計測（`SheetDbDiagnostics`）

### 作らないもの

- ファイルの変更を常に見張ること（`FileSystemWatcher`）。エディタに戻ったときに調べれば足りる。ブック 50 冊の大きさと更新時刻を調べるのは軽い（**推測**。fixtures I-06 で測る）

## 制約

- `Obelune.SheetDb.Editor` に入る。UnityEditor の API はメインスレッドだけで呼ぶ
- 読み込み中も、エディタの 1 フレームを 16 ms 以上止めない

## 完了条件
