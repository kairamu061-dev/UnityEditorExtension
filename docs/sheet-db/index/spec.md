# index 仕様

## 機能一覧

| # | 機能名 | 説明 | テストケース |
|---|--------|------|------------|
| 1 | 主キーで引く | テーブルと主キーの値から、行の番号を返す | U-01 |
| 2 | 主キーの重複 | 同じ値が 2 行以上あれば、2 行目以降を問題にする。引くときは最初の行を返す | U-02 |
| 3 | 空の主キー | 主キーが値なしの行を問題にする | U-03 |
| 4 | 参照の解決 | `ref:` の列の各行について、参照先の行の番号を求める。参照先の主キーが `int` なら数値として、`string` なら文字列として比べる | U-04, U-05 |
| 5 | 参照切れ | 参照先に見つからない値を問題にする。空のセルは「参照なし」で問題にしない | U-06 |
| 6 | 参照先テーブルがない | その列を問題にし、すべての行を「解決できない」にする | U-07 |
| 7 | 参照元 | ある行を参照している（テーブル, 列, 行）の一覧を返す | U-08 |
| 8 | ブックの差し替え | 1 冊のブックを新しい内容に差し替えた Database を作る。参照・参照元・問題が、全部を作り直した場合と一致する | U-09 |
| 9 | 検索 | 文字列の値・数値の値（`string` の書き方にしたもの）の部分一致。大文字小文字を区別しない。範囲は全テーブルか 1 テーブル | U-10, U-11, U-13 |
| 10 | 絞り込みの検索 | 直前の検索語を含む語で検索したとき、直前の結果の中だけを探す。結果は最初から探した場合と一致する | U-12 |
| 11 | テーブル名の重複 | 同じ名前のテーブルが複数のブックにあれば問題にし、ブックのパスの順で後の方を外す | U-14 |

## エラーケース

| 条件 | メッセージ / 挙動 |
|------|------------------|
| 主キーの列が `int` / `string` 以外 | 問題にし、`string` の書き方にして索引を作る |

## 未対応ケース

- 正規表現・単語の境目での検索
- 列を指定した検索（`name:sword` のような書き方）。必要になったら足す
