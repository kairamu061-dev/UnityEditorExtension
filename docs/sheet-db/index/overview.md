# index 概要

親: [sheet-db](../overview.md)

## 目的・背景

全ブックの TableData をまとめて、読み取り専用のデータベース（`Database`）を作る。主キーで行を引く・参照を解決する・参照元を逆に引く・検索する、を目標の速さで行う。

## スコープ

### 作るもの

- 主キーの索引、主キーの重複・空の検出
- 参照の解決（ブックをまたぐ）と参照切れの検出
- 参照元の逆引き
- テーブル名の重複の検出
- 検索（部分一致、大文字小文字を区別しない）
- 1 冊のブックだけを差し替えた Database を作ること

### 作らないもの

- 並べ替え（window が、表示する列について行う）

## 制約

- `Obelune.SheetDb.Core` に入る。スレッドを選ばない。作った Database は変更しない（`../design.md` のスレッド）
- 性能の目標（`../spec.md`）: 検索は 1 打鍵 50 ms、ジャンプは 16 ms

## 完了条件

- `test-cases.md` の U-01〜U-14 が通る
- fixtures I-03・I-05・I-06 で目標を満たす
