# 用語集

このプロジェクトで使用するドメイン固有の用語を定義する。
実装・設計・仕様書内で用語を使う際はここに定義されたものに統一する。

---

| 用語 | 定義 |
|------|------|
| Obelune | このプロジェクトのコード名。パッケージ名（`com.obelune.*`）・名前空間（`Obelune.*`）・メニュー（`Tools/Obelune/`）の頭に付ける。意味はない |
| 拡張機能 | Unity エディタに機能を追加するもの 1 つ分。1 つの拡張機能が 1 つの機能エリア（`docs/<機能エリア>/`）と 1 つのパッケージに対応する |
| パッケージ | UPM（Unity Package Manager）の配布単位。`package.json` を持つフォルダで、拡張機能ごとに 1 つ作る |
| 埋め込みパッケージ | `UnityProject/Packages/` の中に置いたパッケージ。開発用プロジェクトから直接編集でき、そのまま配布物になる |
| 開発用プロジェクト | パッケージを開発・動作確認するための Unity プロジェクト（`UnityProject/`）。配布はしない |
| 利用側プロジェクト | パッケージを git URL で取り込んで使う、別の Unity プロジェクト |
